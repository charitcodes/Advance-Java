# MVC Calculator

## Overview
This project demonstrates the Model-View-Controller (MVC) design pattern by implementing a calculator application in Java.

## Technologies Used
- Java
- MVC Architecture
- Visual Studio Code

## Project Structure
- Model - Handles calculation logic and data.
- View - Displays the calculator interface.
- Controller - Connects the Model and View and handles user actions.

## Prerequisites
- Java JDK installed
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Locate the main Java class.
3. Run the main class.
4. Test the calculator operations.
