# HTML to JSP Experiment

## Overview
This experiment demonstrates how static HTML pages can be converted into JavaServer Pages (JSP) for use in a Java web application.

## Technologies Used
- HTML
- JSP
- Java
- Apache Tomcat
- Visual Studio Code

## Concepts Covered
- JSP page structure
- Embedding Java-related dynamic content in JSP
- Deploying JSP pages on a servlet container

## Prerequisites
- Java JDK installed
- Apache Tomcat configured
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Review the HTML and JSP files.
3. Configure the required Tomcat server.
4. Deploy the web application.
5. Open the JSP page in a browser through the local server.
