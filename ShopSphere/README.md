# ShopSphere – E-Commerce Web Application

## Overview
ShopSphere is a Java-based e-commerce web application developed using JSP, Servlets, JDBC, and MySQL.

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- MySQL
- Maven
- Apache Tomcat
- HTML, CSS, JavaScript, Bootstrap

## Features
- User registration and login
- Product browsing and product details
- Shopping cart and wishlist
- Checkout and order management
- User profile and address management
- Admin dashboard and product management

## Project Structure
- `web/` – Maven web application
- `web/src/main/java/` – Java source code
- `web/src/main/webapp/` – JSP pages and web resources
- `web/pom.xml` – Maven configuration

## Prerequisites
- Java JDK
- Maven
- MySQL
- Apache Tomcat
- Visual Studio Code or another Java IDE

## How to Run
1. Configure the MySQL database and update the application's database settings.
2. Open the `web` folder as a Maven project.
3. Build the project using Maven.
4. Deploy the generated WAR file to Apache Tomcat.
5. Start Tomcat and open the application in a browser.
