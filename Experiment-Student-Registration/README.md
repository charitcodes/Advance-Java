# Student Registration System

## Overview
This project demonstrates a student registration application developed using Java.

## Technologies Used
- Java
- Object-Oriented Programming
- Visual Studio Code

## Features
- Student registration form
- Input collection and handling
- Basic validation, if implemented

## Prerequisites
- Java JDK installed
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Locate the main Java source file.
3. Run the main class.
4. Test the student registration functionality.
