# Java Server-Client Experiment

## Overview
This project demonstrates communication between a server and a client using Java networking concepts.

## Technologies Used
- Java
- Socket Programming
- TCP/IP Networking
- Visual Studio Code

## How It Works
1. The server starts and listens for client connections.
2. The client connects to the server.
3. The client and server exchange messages.
4. The connection closes when communication is complete.

## Prerequisites
- Java JDK installed
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Locate the server and client Java classes.
3. Start the server first.
4. Run the client in a separate terminal.
5. Test the communication between them.
