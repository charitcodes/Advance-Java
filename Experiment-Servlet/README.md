# Java Servlet Experiment

## Overview
This project demonstrates Java Servlets and how they handle HTTP requests and responses in a Java web application.

## Technologies Used
- Java
- Jakarta Servlets
- Apache Tomcat
- HTML
- Visual Studio Code

## Concepts Covered
- Servlet lifecycle
- Handling HTTP requests and responses
- Request and response objects
- Web application deployment

## Prerequisites
- Java JDK installed
- Apache Tomcat configured
- Required Servlet API dependency
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Check the Servlet source files and project configuration.
3. Configure the Tomcat server and required dependencies.
4. Build and deploy the application.
5. Open the application URL in a browser.
