# Java RMI Experiment

## Overview
This project demonstrates Remote Method Invocation (RMI) in Java, allowing an object in one Java application to invoke methods on an object in another application.

## Technologies Used
- Java
- Java RMI
- Visual Studio Code

## How It Works
1. Define a remote interface.
2. Implement the remote interface.
3. Start the RMI server and register the remote object.
4. Run the client to invoke remote methods.

## Prerequisites
- Java JDK installed
- Visual Studio Code with Java extensions

## How to Run
1. Open the project folder in VS Code.
2. Locate the server and client Java classes.
3. Start the server first.
4. Run the client and test the remote method calls.
